Présentation
============

GeoITV est un plugin développé par NAOMIS pour QGIS. Il permet d’importer et de traiter les résultats d’inspections télévisées de réseaux d’assainissement, en extrayant les informations des fichiers TXT normés et en les intégrant dans une base de données SIG.

Fonctionnalités principales :
- Lecture et parsing de fichiers ITV au format NF EN 13508-2+A1
- Insertion automatique des données dans la base de données
- Interface graphique intégrée à QGIS
- Gestion des logs et de la progression
