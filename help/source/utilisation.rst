Utilisation
===========

1. Ouvrir QGIS et activer le plugin GeoITV.
2. Utiliser l’interface pour sélectionner un fichier ITV à importer.
3. Suivre la progression via la barre de progression et les logs.
4. Les données sont insérées automatiquement dans la base de données.

Pour plus de détails, se référer à l’onglet « Aide » du plugin.
