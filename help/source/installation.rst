Installation
============

1. Copier le dossier du plugin dans le répertoire des plugins QGIS.
2. Installer les dépendances Python nécessaires (voir requirements).
3. Activer le plugin dans QGIS via le gestionnaire de plugins.

Dépendances principales :
- QGIS (PyQt, qgis.core)
- psycopg2 (pour la connexion PostgreSQL)
